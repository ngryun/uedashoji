# 요나고미나미고등학교 설악고등학교 2026 국제교류 — 3D 갤러리

우에다 쇼지 사진미술관(高松伸 설계) 콘셉트의 Three.js 1인칭 가상 미술관.
2026년 7월 12–15일 국제교류 사진 218점과 영상 16점을 2층, 날짜별 4개 전시실에 전시.
Day 1·2는 1층, Day 3·4는 2층에 배치했습니다. 로비 계단과 Day 2 관람 종료 지점의 계단으로 2층에 올라갈 수 있습니다.

## 실행

```bash
node tools/serve.mjs
# → http://localhost:8735
```

(브라우저 보안 정책상 로컬 서버가 필요합니다. `file://`로 직접 열면 사진이 로드되지 않습니다.
같은 Wi-Fi의 휴대폰에서 보려면 `http://<맥의IP>:8735`로 접속하세요.)

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml`이 공개용 파일만 모아 자동 배포합니다.
원본 `img/`, 변환 추적 정보 `assets/.source-map/`, 로컬 설정은 Git 및 배포 대상에서 제외됩니다.

방명록 스크린의 한·일 문장 줄바꿈, 긴 글 페이지 분할, 로컬 구독 갱신도 검증합니다.

## 사진을 추가/변경하려면

`img/` 날짜 폴더에 원본을 넣고 다시 실행:

```bash
tools/convert.sh
```

원본 경로·크기·수정 시각이 바뀐 항목만 다시 변환합니다. 중간에 사진을 추가하거나 교체해도 번호가 바뀐 결과물을 안전하게 갱신하며, `manifest.json`은 모든 변환이 성공한 뒤 교체됩니다. 전시실 크기와 배치는 사진 수에 맞춰 자동 계산됩니다.

## 메모

- 다이센 원경은 원본 사진의 산·하늘 부분을 비율에 맞춰 표시하며, 카메라 이동에 따른 배경판의 확대와 끝 노출을 줄였습니다. 창 앞에는 연못과 낮은 입체 둔덕을 두고, 수면은 같은 사진을 이용해 시점에 맞는 반사를 표현합니다.
- 산 위의 옅은 구름은 천천히 흐르고 풀은 뿌리를 고정한 채 잎 끝만 흔들립니다. 구름과 수면 반사는 같은 시간을 사용하며, 기존 메시와 구름용 작은 노이즈 텍스처 하나를 재사용합니다. 모바일에서는 구름 표현을 단순화합니다. 관람을 멈추거나 탭이 숨겨진 경우, 또는 동작 줄이기 설정에서는 구름·풀·물결의 움직임을 멈춥니다.
- 1층 로비는 미세 요철이 있는 콘크리트·석재 바닥, 따뜻한 선형 조명, 서쪽 벽 쪽 목재 벤치 2개를 사용합니다. 창틀과 계단의 햇빛 그림자는 초기화 때 한 번 계산하며, 모바일은 더 작은 텍스처를 사용합니다. 벤치에는 충돌 처리가 있고 중앙 통로는 비워 두었습니다.
- 1층 로비 계단 출발점 옆 남쪽 벽의 **교류의 기억 · 交流の思い出** 스크린에 최신 방명록 최대 200개를 무작위 순서로 표시합니다. 한 바퀴마다 순서를 다시 섞고 같은 글이 연달아 나오지 않게 하며, 긴 글의 페이지 순서는 유지합니다. 화면당 10–25초, 긴 글은 여러 화면으로 나누며, 3.5m 이내에서는 전환을 멈춥니다. 클릭·탭하면 전체 방명록을 엽니다. 로컬 모드에서는 이 기기에 저장된 글임을 표시합니다.
- 동영상은 액자 없이 벽면 투사광 형태로 전시되며 9m 이내 접근 시 자동 재생(음소거), 가까운 2개만 동시 재생
- 1층 로비 계단과 Day 2 관람 종료 지점의 계단으로 2층 이동 가능
- 1F / 2F 버튼과 숫자키 1 / 2는 각 층 로비로 바로 이동하는 보조 기능
- 사진은 거리순으로 모바일 최대 36장, 데스크톱 최대 56장만 GPU에 유지
- 전시 화면은 640px 썸네일을 사용하고 확대 보기에서만 1600px 원본 로드
- URL에 `?touch=1`을 붙이면 데스크톱에서도 터치 UI 강제 표시 (테스트용)
- `assets/bgm.mp3` 파일을 넣으면 입장 시 은은한 배경 음악이 루프 재생됩니다. 좌측 상단 ♪ 버튼으로 켜고 끄며, 확대 보기에서 영상을 볼 때는 자동으로 볼륨을 낮춥니다. 파일이 없으면 버튼도 나타나지 않습니다. (음원은 저작권 이용 범위를 확인해 직접 준비)

## 방문자의 발자국

수동으로 관람한 사람의 짧은 발자국이 바닥에 최대 60일 동안 남습니다. 좌우 6걸음씩, 탭별 방문에서 공간당 최대 두 구간을 남기며 구간 사이에는 30초와 4m 간격을 둡니다. 자동 관람·점프·계단·비밀의 방에서는 기록하지 않습니다. 사진 확대 보기처럼 제자리에서 멈춘 경우에는 형성 중이던 발자국이 유지되고, 멈춘 사이 0.8m 이상 움직였거나 다른 공간으로 이동하면 버립니다. 오래된 흔적은 흐려지고, 밀집 구간은 통째로 생략합니다. 표시 상한은 데스크톱 144개, 모바일 72개입니다.

여섯 걸음 끝에는 기록 날짜가 작은 바닥 라벨로 표시됩니다. 입장 화면에서 **별명**(최대 8자, 선택)을 적으면 라벨에 별명이 함께 공개됩니다. 비워 두면 날짜만 남습니다. 별명은 이 브라우저에 기억되며, 방명록 이름이나 학교와는 연결되지 않습니다. 부적절한 별명은 Firebase 콘솔의 `visitorTraces` 컬렉션에서 해당 문서를 삭제해 지웁니다.

입장 화면과 좌측 상단 **발자국 켜짐/꺼짐** 버튼에서 내 기록을 켜거나 끌 수 있습니다. 설정은 이 브라우저에 유지됩니다. 공유 실패 시 내 발자국은 현재 화면에만 나타나며 상태 안내가 표시됩니다. 실제 방문 기록이 없는 공간에는 다른 사람의 흔적을 생성하지 않습니다. 2D 사진 목록에서는 발자국을 기록하지 않습니다.

구현은 `visitor-traces.js`, 공유 계층은 `social.js`에 있습니다. **운영 공유를 활성화하려면 [Firebase 배포 절차](FIREBASE_SETUP.md#방문-발자국-공유-60일)에 따라 규칙·인덱스·TTL을 먼저 설정해야 합니다.**
